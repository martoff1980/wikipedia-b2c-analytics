# Wikipedia B2C Demand & Market Analytics Skill

Ця навичка дозволяє агенту оцінювати ринковий інтерес до тем, курсів, продуктів та нових мовних локалізацій за допомогою даних Wikimedia Analytics REST API.

## Коли використовувати навичку

Застосовуй цю навичку, коли користувач ставить питання стосовно:

- Оцінки перспективності запуску нових фіч/курсів/тем для B2C-продуктів.
- Порівняння динаміки інтересу між різними країнами / мовними розділами Wikipedia (наприклад, `pl`, `cs`, `uk`, `en`, `de`).
- Перевірки стійкості тренду (чи це довгострокове зростання, чи тимчасовий хайп/медіа-спалах).
- Підготовки готового PDF-звіту та графіків для інвесторів/продукт-менеджерів.

## Доступний інструмент виконання

Для аналізу НЕ потрібно обробляти великі масиви даних у контексті LLM. Використовуй скрипт `run_analysis.py` через системне виконання CLI (bash / terminal).

### Команда запуску

```bash
python run_analysis.py --queries config.json
```

## Створення файлу конфігурації `config.json`

```JSON
{
  "project_name": "Бенчмарк мовних курсів",
  "period_months": 24,
  "items": [
    {"topic": "Intermittent fasting", "lang": "pl"},
    {"topic": "Głodówka lecznicza", "lang": "pl"},
    {"topic": "Přerušovaný půst", "lang": "cs"}
  ],
  "output_pdf": "reports/intermittent_fasting_report.pdf",
  "output_chart": "reports/intermittent_fasting_chart.png"
}
```

## Інструкція для Агента

1. Ідентифікація тем та мов:

- Визнач теми та відповідні мовні коди (pl — польська, cs — чеська, uk — українська тощо).

- За потреби уточни точні назви статей Wikipedia мовою оригіналу (наприклад, "Intermittent fasting" -> pl: "Intermittent fasting" або "Dieta nektarowa/Głodówka").

2. Запуск аналізу:

- Сформуй JSON-конфігурацію та виконай `python run_analysis.py --queries '...'`.

3. Интерпретація вихідного JSON:

Скрипт поверне структурований підсумок з метриками:

- `cagr_or_yoy`: Річний відсоток зростання/падіння.

- `volatility_cv`: Коефіцієнт варіації (якщо > 0.8, зростання нестабільне, є спалахи).

- `confidence_score`: Оцінка від 0 до 100 (враховує обсяг, стабільність та органучність тренду).

- `recommendation`: Автоматичний первинний висновок.

4. Формування відповіді Користувачу:

- Надай стислу аналітичну відповідь.

- Чітко зазначай припущення та обмеження (перегляди Wikipedia свідчать про загальну обізнаність/цікавість, але не дорівнюють конверсії в покупку).

- Повідом про згенеровані файли (PNG-графік та PDF-звіт на 1 сторінку).
